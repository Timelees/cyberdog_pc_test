# 踢球动作步态参数调试

基于Cyberdog2官方仿真程序，设计自定义动作参数文件，便于移植实机

## 编译与安装

下载源码
```bash
git clone 
```

在docker中补充编译安装lcm

```bash
cd lcm
mkdir build
cd build
cmake -DLCM_ENABLE_JAVA=ON ..
make
sudo make install
```

编译

```bash
cd src/src/cyberdog_action_sim/cyberdog_sim
colcon build --merge-install --symlink-install --packages-up-to cyberdog_locomotion cyberdog_simulator
```

## 运行

修改 cyberdog_sim/src/cyberdog_locomotion/control/motion_list/cyberdog2/user/parameter/cyberdog2_user88_FR_lift.toml 中的相关参数，运行仿真进行验证

终端1

```bash
source install/setup.bash
ros2 launch cyberdog_gazebo gazebo.launch.py
```

终端2

```bash
source install/setup.bash
ros2 launch cyberdog_gazebo cyberdog_control_launch.py
```

终端3

运行验证脚本验证动作可行性

```bash
python3 "cyberdog_sim/src/send_fr_lift.py"
```

## 实机部署

使用**src/doc/cyberdog_action修改文件**文件夹下的两个文件

进入cyberdog2底层运动控制板 192.168.44.233

替换以下两个路径的参数文件：

```bash
/robot/robot-software/common/config/cyberdog2-ctrl-user-parameters.yaml

/robot/robot-software/control/motion_list/cyberdog2/user/parameter/cyberdog2_user88_FR_lift.toml
```

将src/doc/motion放在cyberdog2源码工作区下，使用小米的docker对motion_manager进行交叉编译

启动小米docker

```bash
docker run --privileged=true -it -v /home/lee/code/cyberdog2_ws:/home/builder/cyberdog2_ws cyberdog_img:1.0 bash
```

编译

```bash
source /opt/ros2/galactic/setup.bash

colcon build \
  --merge-install \
  --packages-up-to motion_manager \
  --parallel-workers 2 \
  --cmake-args \
    -DCMAKE_PROJECT_INCLUDE=/home/builder/cyberdog2_ws/src/.motion_manager_build_targets.cmake \
    -DCMAKE_HAVE_PTHREAD_H=ON \
    -DTHREADS_HAVE_PTHREAD_ARG=ON \
    -DCMAKE_C_FLAGS=-pthread \
    -DCMAKE_CXX_FLAGS=-pthread
```

部署编译产物：

```bash
bash src/env/deploy_motion_manager.sh
```

运行实机验证脚本

```bash
python3 "cyberdog_sim/src/send_fr_kick_robot.py"
```

也可使用keyboard_input功能包，启动节点，使用按键k执行踢球动作
